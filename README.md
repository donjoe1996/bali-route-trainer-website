# Bali Route Trainer

Drive the real roads of Bali on your Android phone: the whole island's roads from
OpenStreetMap, real hills, traffic, and day and night. Free, no ads, no tracking.

- **Website:** https://donjoe1996.github.io/bali-route-trainer-website/
- **Download the latest APK:** [bali-route-trainer.apk](https://github.com/donjoe1996/bali-route-trainer-website/releases/latest/download/bali-route-trainer.apk)
  (Android 7.0+, 64-bit)
- **Problems or ideas:** [open an issue](https://github.com/donjoe1996/bali-route-trainer-website/issues)
- **Privacy:** [privacy policy](https://donjoe1996.github.io/bali-route-trainer-website/privacy-policy.html)

This repository holds only the website and the app's releases; it is published automatically
by the game's build.
